# Nordic Sales Solutions — Salesforce CRM Implementation

## Project Overview

Nordic Sales Solutions is a fictional Finnish B2B company.

The company needs a Salesforce CRM system to manage
leads, customers and sales opportunities.

## Business Requirements

1. Track potential customers using Leads.
2. Manage Accounts and Contacts.
3. Track sales deals using Opportunities.
4. Improve data quality using validation rules.
5. Automate follow-up tasks using Salesforce Flow.
6. Monitor sales performance using dashboards.
7. Control access using permission sets.

## Technologies

- Salesforce Sales Cloud
- Salesforce Flow
- Reports and Dashboards
- Permission Sets
- Data Loader
